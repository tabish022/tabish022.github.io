# Tabish Afzal — Data Analyst Portfolio

**Live site:** [tabish022.github.io](https://tabish022.github.io)

A personal portfolio that presents my data analytics work in one place: five end-to-end projects, certifications, education, resume and a contact form. It is a single-page site built with plain HTML, CSS and JavaScript, and it works on desktop and mobile in both light and dark themes.
